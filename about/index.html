About

Abdalkreem / ALR

I'm a security researcher and bug bounty hunter. I publish as ALR (@0xalr on Medium).

My write-ups document real vulnerabilities from bug bounty programs, with step-by-step accounts of how each one was found. They tend to start with reconnaissance: reading client-side JavaScript, decompiling client binaries, and enumerating API endpoints the UI never shows. From there they follow up on the small inconsistencies that recon turns up.

Topics so far include insecure direct object references and broken access control, an authentication bypass through a bare Authorization header, account takeover through an unprotected email-change endpoint, and an XXE that I escalated to an unauthenticated internal Redis instance.

I write these so other hunters can reuse the thinking behind them, not only read about the result.
