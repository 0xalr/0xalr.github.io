What is idor?

An IDOR (Insecure Direct Object Reference) vulnerability occurs when an application allows a user to access or modify data/resources within the system simply by changing the ID in the request, without performing permission verification.

This means that the attacker changes a number or value in the URL or Request Parameter (such as: user_id=123 to user_id=124) → and thus accesses information or resources that are not related to his account.

For Example:

GET /profile?user_id=100   ← Myaccount
GET /profile?user_id=101   ← victi

Vulnerability Findings

When I was searching the app for hidden endpoints, I found a strange endpoint like this:
`/xxxxxxxapi/v2/User/Profile`

As always, I tried playing with the endpoint like add, remove, add, update and vicim-id as follows:

/xxxxxxxapi/v2/User/Profile/remove
/xxxxxxxapi/v2/User/Profile/add
/xxxxxxxapi/v2/User/Profile/update
/xxxxxxxapi/v2/User/Profile/{id-victim}
/xxxxxxxapi/v2/User/Profile/{id}/remove
/xxxxxxxapi/v2/User/Profile/{id}/update
/xxxxxxxapi/v1/User/Profile/remove/{id}
/xxxxxxxapi/v1/User/Profile/add
/xxxxxxxapi/v1/User/Profile/update
/xxxxxxxapi/v1/User/Profile/{id-victim}
/xxxxxxxapi/v1/User/Profile/{id}/remove
/xxxxxxxapi/v1/User/Profile/{id}/update
etc..

Unfortunately, after several attempts, I was expecting a 500 error, but it always returned a 404 error.

But………………………….

I deleted the profile and entered the previous attempts like:

/xxxxxxxapi/v2/User/remove
/xxxxxxxapi/v2/User/add
/xxxxxxxapi/v2/User/update
/xxxxxxxapi/v2/User/{id-victim}
etc...

Indeed, when I tried the following endpoint /xxxxxxxapi/v2/User/{id-victim}, it returns the user information, but unfortunately the user ID on the site is gguid.

I tried to search for endpoints that return the user ID based on gguid but I didn’t get anything.

But……….

It occurred to me to try registering an account using the victim’s email.

As I expected, the victim’s `guid` returned to me in response with a message alerting me to the user’s presence on the system.

Impact

Disclosure of all user information, including meta data.
