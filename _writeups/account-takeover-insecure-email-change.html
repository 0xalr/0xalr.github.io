Introduction.

While conducting testing on one of the platforms, I discovered a serious Account Takeover (ATO) vulnerability that allows an attacker to take complete control of any user’s account by changing the email associated with the account to one controlled by the attacker, without any additional verification or authentication.

How I Discovered the Vulnerable Endpoint

I started creating a new account on the platform and trying out the different features (login, edit data, recover password, etc.).

I noticed that most of the operations are done via the REST API using the path:

/Api/v2.0/

This gave me the impression that the platform relies heavily on API endpoints to manage users.

When I tested all the functions in the application I reviewed the endpoints I registered in the burp.

I noticed the following endpoints that attracted me:

/Api/v2.0/User/
/Api/v2.0/Profile/
/Api/v2.0/Account/

I sent the request to the repeater which has the following endpoint `/Api/v2.0/User/`

I started trying some popular words that create actions for the user like Update, Delete, Rename, edit, {id-victim-user}

/Api/v2.0/User/delete
/Api/v2.0/User/add
/Api/v2.0/User/Rename
/Api/v2.0/User/Update
/Api/v2.0/User/edit
/Api/v2.0/User/{id-victim-user}

I was surprised that the following endpoint `/Api/v2.0/User/Rename` is working and returning an error in response asking for the `emailId` and `renameEmailId` parameters.

one something that came to my mind is to put the victim’s email in the emailId parameter and the attacker’s email in the renameEmailId parameter.

After testing, it became clear that it is possible to change any user’s email to my own, meaning that the process is done without any Authorization or Ownership Validation.

Impact

Full control over any user’s account.

Report

📌 Conclusion

This vulnerability demonstrates the danger of neglecting verification when updating sensitive data such as email. Despite its technical simplicity, its impact is devastating, as it allows an attacker to take over a full account with the click of a button.
